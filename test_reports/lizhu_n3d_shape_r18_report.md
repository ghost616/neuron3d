测试脚本自身曾出现 3 处**判据写法**问题，均已修正并复跑，**与被测代码无关**，按"测试方法学"记录：

2. T4 探针输出与工作区输出的唯一差异是落盘信息行中打印的**绝对路径**（探针根 vs 工作区根），掩掉运行根后逐字符相同。
3. T6 首版把 `verify_shape.py` 的 2 处**既有、有意**的上游 import 计入"零上游 import"，收敛口径为"生产代码零上游 import + `verify_shape.py` 的上游 import 与 R17 基线逐项一致"。
