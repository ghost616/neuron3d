## 专长

- 精通 PyTorch 张量化 / 向量化实现：能在不出现"Python for 循环遍历神经元或突触"的前提下完成 FCC 晶格构造、稀疏连接构建与整层向量化分层递推。
- 精通三维几何度量与等值面推导（L2 球 / L∞ 立方体 / 轴向圆柱 `max(‖p_xy‖₂, |z|/λ)`），能把"空间形状"正确落成**生长度量**而不是**裁剪掩码** —— 已知陷阱：只改裁剪掩码会使选取结果与球体逐位相同，等于什么都没改。
- 熟练设计确定性 tie-break（`(流向轴坐标, 壳层名次)` 字典序）、形状专属尺寸窗口校验与契约断言（最近邻距 2H、连通性下限）。
- 熟悉本仓库变体落地口径：**新模块 + 自包含拷贝**，使上游模块保持零改动以规避回归风险；熟悉产物指纹防撞名纪律与"产物字节确定性 / SHA256 语义"陷阱。

## 其他约定

- 本模块**自包含**：不 import `n3d_sphere` / `n3d_proto`，所需实现全部在模块内独立完成。
- 严格遵循本模块 `current_spec.md` 的张量形状契约；几何量一律在 `__init__` 预计算并 `register_buffer`，`forward` 中不得重算。
- 所有实测数字必须来自真实执行，**禁止臆造运行结果**；前置探针数字必须显式标注"探针、非实测"。
- 引用 `|S_in|` / `|S_out|` 等**逐 seed 随机量**时必须标注 seed 与跨 seed 波动范围，不得当作设计常数。
- 涉及多组对比时必须标注**共享 seed 前提**；默认（`shape=sphere`）分支须与二期张量级逐位一致。
