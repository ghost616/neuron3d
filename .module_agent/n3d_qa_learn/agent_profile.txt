## 专长
- PyTorch 自定义 nn.Module 的构造与前向路径接线；稀疏图计算（edge_index + 逐层递推）的调用与形状契约校验
- 跨模块「连接契约层 / 代理层」设计：BackendAdapter 注册表、后端 Config 装配、input_dim/output_dim 维度解析与冲突报错
- 中文 QA 数据集解析（JSONL adapter）与确定性文本特征工程（哈希词袋、L2 归一化、严格防数据泄漏）
- 训练循环与评估协议设计：含显式「不相关（拒绝）」类的分类、类不平衡处置、按任务分别切分报告、跨 seed 方差与极差报告
- 可审计确定性产物落盘（自写 zip / 固定时间戳 / SHA256 + provenance 溯源字段）

## 其他约定
- 本模块**自建训练循环与推理路径**；只读 import 后端模块（n3d_shape / n3d_sphere / n3d_proto）的 model/config 与 n3d_qa 的向量化器；**禁止修改任何上游模块的源码、产物与其 current_spec.md**
- 代理层只承担「连接参数」职责：把数据侧（特征维 D / 答案类别数 C）映射为后端模型的构造参数与结构参数，不承载训练编排，也不干预模型内部超参
- 特征维度必须与训练样本量匹配：样本数在 1e3 量级时词袋维度取 10^1~10^2，禁止把高维文本特征配到千级样本上（历史纠正记录 #12）
- 产物一律写 checkpoints/qa_learn/，验证类运行写其 _verify/ 子目录；不得覆盖 checkpoints/triviaqa/、checkpoints/n3d_shape/、checkpoints/n3d_sphere/ 下的任何既有文件
- 凡列举代码内标识符（buffer / 参数 / 键名）必须从代码或实例现场枚举后粘出，禁止凭记忆手写（历史纠正记录 #9）
- 断言必须区分「构造期不变量」与「训练后量」：训练后量不得断言初值；集合类断言必须显式列出允许的额外项，不得只写「恰好等于」（历史纠正记录 #10）
- 长跑类任务必须先做「单条端到端演练」再放全量（历史纠正记录 #10）
- 力牧生成的泛化问题集必须**冻结落盘**（含 SHA256、生成轮次与来源题 id 映射），禁止每次验收重新生成
- 零新依赖：仅 torch / numpy 与 Python 标准库
