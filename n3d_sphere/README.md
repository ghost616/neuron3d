# N3D 二期架构变体：球形有向拓扑

> **版本定位（必读）**：本模块是 N3D 的**二期架构变体**，与一期原型 `n3d_proto/`
> **并列存档**。一期 `n3d_proto/` 下的任何文件**一律未被修改**，其默认行为与既有产物
> （`checkpoints/n3d_model_full.pt` / `n3d_model_highacc.pt` / `n3d_model_capacity.pt`）
> 逐位不变（SHA256 见第 6 节）。本模块自包含，不 import `n3d_proto` 的任何模块。
>
> **默认路径逐位不变**：`python n3d_sphere/train.py --smoke-test`（默认 `topology=cube`）
> 的 `loss` 与一期同为 **2.419689**，见第 5 节门槛 B。

---

## 1. 为什么做这个变体

一期七轮实验已把「容量维度」（N / y_in,y_out / D / T）与「拓扑种子」（seed 42/7/2024/123）
逐一证否：四轮全量运行的 test_acc 全部落在 **97.70% ~ 97.84%** 的 0.14pp 带内，19 个种子
极差仅 0.35pp；而**同控制变量、参数量更少**的普通 MLP（784→2048→10，1,628,170 参数）
达到 **98.64%**，比主模型（1,691,730 参数）高 **+0.80pp**。

因此一期结论是「**瓶颈在架构，而非容量或数据**」。二期变体的目标只有一个：
**用几何结构向四步闭环注入方向性与层次性，看能否突破一期架构的信息损耗瓶颈。**
具体手段是把一期「立方体空间 + 各向同性突触分布」换成
「**球形空间 + 沿全局流向轴的半球切分**」，使信息在空间上具有可辨识的上行方向。

## 2. 几何定义

### 2.1 两种拓扑分支

| 项 | `topology="cube"`（默认，一期几何，**逐字保留**） | `topology="sphere"`（二期新增） |
| --- | --- | --- |
| 神经元分布 | `[0, L]^3` 均匀（保留 `min_neuron_dist=0.08` 拒绝采样） | 以原点为球心、**与立方体等体积**的球（半径 `R = L·(3/4π)^(1/3) ≈ 0.620350`）内**按体积均匀**，同样保留拒绝采样 |
| 输入突触 | 所属神经元周围 **H 半径球体**内按体积均匀 | 半径 H 球内按体积均匀，**限制在全局流向的负半球（−axis）** |
| 输出突触 | 所属神经元周围 **H 半径球体**内按体积均匀 | 半径 H 球内按体积均匀，**限制在全局流向的正半球（+axis）** |
| 连接规则 | 输出突触与输入突触的欧氏距离 ≤ D 才建边（**与一期同一份代码**） | 同左 |

> **设计说明更正（重要）**：一期突触采样**不是**「H 立方体」，而是「神经元周围
> **H 半径球体**内按体积均匀」（`_sample_synapse_positions`：方向球面均匀 +
> `r = H·u^(1/3)`）。二期**没有**把 cube 采样改成球体，cube 分支逐字保留。
> 等体积球半径保证神经元**密度与一期一致**（`N/L³ = N/((4/3)πR³)`）。

### 2.2 半球切分的实现（为什么不是拒绝采样）

sphere 分支在生成方向后，把流向轴分量**翻转为目标半边**（`d_axis ← sign·|d_axis|`）：

```python
direction = torch.randn((n, y, 3), generator=gen)      # 球面均匀方向
direction = direction / direction.norm(dim=-1, keepdim=True)
axis_comp = direction[..., axis_index]                  # 与立方体分支同一随机流
direction[..., axis_index] = sign * axis_comp.abs()     # sign=-1 输入 / +1 输出
radius = H * u.pow(1.0 / 3.0)                           # 体积均匀
```

该翻转是**测度保持**的：目标半球内任一方向恰好由「原始方向」与「翻转后的方向」两种
来源各命中一次，因此仍是**半球内均匀分布**——等价于在半球上做拒绝采样，但不需要
额外消耗随机数、也不引入重试上限（`y=8` 时若用拒绝采样，会有约 `1/256` 的概率
出现未分配的突触）。翻转是确定性操作，且**只发生在 sphere 分支**，对 cube 随机流
零影响（下文门槛 B 以逐位相等实测证明）。

### 2.3 关键几何性质：**上行偏置，而非严格 DAG**（如实报告）

设神经元沿流向轴的间距为 Δz，输入突触偏移 δ_in ∈ [−H, 0)、输出突触偏移 δ_out ∈ (0, H]，
则边的流向轴间距为

```
gap = z_out_syn − z_in_syn = Δz + δ_out − δ_in ,   δ_out − δ_in ∈ (0, 2H]
```

- `gap > 0` = 沿 −axis → +axis 向上传播的**正向边**；
- `gap < 0` = 逆流向下传播的**逆向边**；
- 因 `|gap| ≤ D`，可形成正向边的神经元间距区间为 `Δz ∈ [−2H, D]`（H=0.1/D=0.15 时
  即 `[−0.2, 0.15]`）——**Δz 为负（神经元在下）时也能形成正向边**，反之亦然。

因此半球切分只保证「每个神经元的出边朝上、入边朝下」，**并不能保证整图是 DAG**。
实测（N=256 / y=8×8 / H=0.1 / D=0.15 / 等体积球 / seed=42）：

| 拓扑 | E | 正向边占比 | **逆向边占比** | gap 均值 |
| --- | --- | --- | --- | --- |
| cube（一期） | 61255 | 0.5009 | **0.4991** | +0.0001（≈0，各向同性） |
| sphere/z（二期） | 61503 | 0.6150 | **0.3850** | +0.0163 |

**结论：球形有向拓扑确实建立了明显的上行方向偏置（正向:逆向 = 61.5% : 38.5%，
对比立方体的 50.1% : 49.9%），但**不是**严格 DAG。** 本文档不对此做任何理想化裁剪，
逆向边占比作为一等统计量随每个产物一起落盘（`topology_stats.reverse_edge_ratio`）。

### 5.3 连通性缺陷 D1 与修复（离朱第 2 轮实测，已修复 + 已固化回归）

**缺陷**：`model.py::_compute_weak_components` 初版用「互为指针
（`scatter_reduce_(hi←lo, amin)` + `scatter_reduce_(lo←hi, amax)`）+ 对称化指针跳跃」，
会把二点循环维持成**非真值的固定点**，使分量被提前劈开。最小复现：
`N=32` 且仅一条边 `(0,1)` 时返回 **32** 个分量（真值 **31**）——连一条边都合并不了。

**影响面**：只影响统计量（`neuron_component_id` 不参与 `forward` / loss / 梯度，
故 `loss=2.419689`、cube 逐位不变、训练数值**均未受影响**），但错误值已落盘进
产物元数据与训练日志，并一度导致本 README 的连通性结论失实。

**修复**：改为「无向投影 + **最小标签传播**（`scatter_reduce(reduce="amin")`，
只可能单调下降、固定点唯一）+ 指针跳跃 `min(nxt, nxt[nxt])`」。
为避免同类错误再次漏出，`model.py` 新增两个自检入口：
* `connectivity_selfcheck()`：7 个**真值已知的合成图** + 真实拓扑上"向量化 vs 独立并查集"的划分比对；
* `_component_stats_crosscheck()` / `_components_of_synthetic_graph()` / `_expected_components()`。

**回归证据**（`python checkpoints/n3d_sphere/_verify/verify_connectivity_regression.py`，

## 8. 结论与后续方向

### 8.1 主结论（判定规则事先固定，未事后挑选）

**「用几何结构注入方向性」这一方向，在本轮实现下没有带来可测量的收益。**

| 对照 | 差值 | 判定（阈值 > 0.3pp 才算有效） |
| --- | --- | --- |
| C（球形有向，97.83%）− A（立方体，97.84%） | **−0.01pp** | 落在 ±0.3pp 噪声带内 → **无显著差异** |
| C（球形有向，97.83%）− B（普通 MLP，98.64%） | **−0.81pp** | 显著更低 → 瓶颈**仍在架构**，未因方向性而改变 |

即：把一期「立方体空间 + 各向同性突触分布」换成「球形空间 + 沿流向轴的半球切分」
（逆向边占比 0.4991 → 0.3850，正向边占比升到 61.5%），**在严格控制变量下
（12 epoch / bs=128 / AdamW 2e-3 / wd=1e-4 / dropout=0.1 / cosine / clip=1.0 /
seed=42 / 全量 60000 / 无增强无标准化），test_acc 变化 −0.01pp，统计上不可区分。**

### 8.2 为什么方向性没有转化为收益（如实归因）

1. **方向性建立得不彻底**：正向:逆向 = 61.5% : 38.5%，仍是「强偏置而非 DAG」。
   38.5% 的边仍然逆流向传播，且 2a 的归一化是"对每个输出突触在其**全部**入边上
   做 softmax"，逆向边与正向边在同一个 softmax 里被一起平均——方向性无法在
   2a 内被区分对待。
2. **覆盖维度没有变化**：静态/动态 2a 覆盖在两种拓扑下都是 1.000000
   （每个输出突触都能拿到非空消息），说明几何改变没有改变"信息覆盖面"这一通路特性。
3. **连通性不是瓶颈**：修复 D1 后确认两种拓扑的神经元层弱连通图都是单连通图，
   即几何改变也没有改变信息的可达范围。
4. **一期归因结论仍然成立**：真正的损耗点（2a 的凸组合压缩、2d 的 LayerNorm 幅度丢失、
   2c 的 ReLU 负侧零梯度、以及缺乏卷积式局部先验）**都没有被"方向性"触及**。
   本轮结果与一期"瓶颈在架构"的判定一致，并额外证否了"几何方向性"这一维度。

### 8.3 后续方向（按预期收益排序）

1. **直接改四步闭环本身**（一期已列出的方向，预期收益最高）：
   去掉/弱化每样本 LayerNorm 的幅度丢失；放宽 2c 的死区（GELU/LeakyReLU/SiLU）；
   让 2a 的边权不必经过分组 softmax（或改为可学习温度）。
2. **让"方向"进入计算而不是只进入几何**：例如按流向轴做**分层（rank/level）划分**，
   仅在"上一层 → 下一层"之间建边（严格 DAG），或对逆向边做权重惩罚；
   当前几何法只改变"哪些边存在"，未改变"边如何被加权"。
3. **引入卷积式局部感受野**：把 `W_in` 换成局部连接/卷积权重，从根上补足归纳偏置
   （一期已判定这是越不过 98.6% 的关键）。
4. **数据侧**（本轮明确排除，需另行申请）：RandomAffine / 平移抖动等增强通常带来
   +0.5~1.5pp。
5. **球半径 R 的扫描**：R=0.800 在保持 E 可用（37082）的同时把逆向边占比降到 0.3168，
   是一个"方向性更强、成本更低"的候选点（本轮因预算未做全量）。

## 9. 统计口径与验收对齐

* 连接稀疏度（规格口径）= **密度** `E/(N*y_out*N*y_in)`，阶段 A 要求 < 0.1；
  `zero_ratio = 1 − 密度` 仅作日志对照，不参与判据；
* `get_connection_stats()` **保持与一期完全相同的 5 个键**
  （`num_edges` / `sparsity` / `zero_ratio` / `avg_out_degree` / `tau`），
  二期新增指标一律放入 `get_topology_stats()`，不破坏既有键的解析；
* 全部拓扑量（含二期新增的 `edge_reverse_flag` / `neuron_component_id` /
  `connected_output_mask`）均在 `__init__` 预计算并 `register_buffer`，
  `forward` 中不重算；`forward` 只额外记录 2a 的非零覆盖标量（不参与计算图）；
* 仍然**禁止 materialize dense `[N*y_out, N*y_in]` 权重矩阵**：连接权重是边级参数
  `W_conn_sparse` [E]，冒烟测试的「附加①边级参数数 == E」「附加②无该形状权重张量」
  两条判据在二期同样 PASS。
