# n3d_qa_learn 模块级依赖清单
#
# 口径（本文件是 **QA 侧依赖的唯一落点**）
# ---------------------------------------------------------------------------
# 1. 本模块使用 torch / numpy 与 Python 标准库；**另有一项可选依赖**
#    `transformers`（及其传递依赖），只在选择 HF 编码器（`encoders.HFTextEncoder`，
#    如注册表里的 `bge-m3`）时才需要 —— **默认口径（`local-hash` / `zh-bag`
#    确定性词袋）不需要它**，未安装时选择 HF 编码器会给出可读报错。
# 2. 后续若确有新增依赖，一律写入**本文件**，**不写入仓库根 requirements.txt**
#    —— 根 requirements.txt 属 **framework 模块**管辖（其内容为 N3D 一期原型的
#    torch / torchvision / numpy 清单），QA 侧依赖不写入根文件。
# 3. 本文件是**口径声明文件**，不被任何脚本以 `pip install -r` 执行；它存在的目的
#    是让"依赖边界"有唯一、可审计的落点。
#
# 依赖清单（第 9 轮新增 `keybert` / `jieba` 一族：第三步 Phase 1 文本侧改造）
# ---------------------------------------------------------------------------
# 用途：`n3d_qa_learn/text_variants.py` 的关键词支（KeyBERT 关键词抽取）
#       与其中文分词（jieba 作 KeyBERT 候选词 tokenizer）。**二者只在生成
#       「关键词支」时需要**；缺失一律**可读报错 + 退码非 0**，不静默跳过。
#
#   keybert              # KeyBERT 0.9.0（关键词抽取骨架）
#   jieba                # 0.42.1（中文分词；KeyBERT 默认按空格切词对中文失效）
#
# 传递依赖（现场实测由 pip 一并装入）
# ---------------------------------------------------------------------------
#   scikit-learn  1.9.1  # keybert 的直接依赖
#   scipy         1.18.1 # scikit-learn 的依赖
#   joblib        1.6.0  # scikit-learn 的依赖
#   threadpoolctl 3.7.0  # scikit-learn 的依赖
#   narwhals      2.26.0 # scikit-learn 的依赖
#   cloudpickle   3.1.2  # joblib 的依赖
#   sentence-transformers 6.1.0
#                        # **keybert 的直接依赖**（本模块**不使用**它的后端；
#                        #   见下「后端口径」。它的 transformers / torch 依赖在本机已满足）
#
# **安装口径（现场实测，不得省略）**
# ---------------------------------------------------------------------------
#   1. `python -m pip install keybert jieba`
#   2. **必须**用 `--only-binary=:all:` 或国内镜像：现场实测 `pypi.org` 下载
#      `scipy` 的 36.7 MB wheel 时**长时间零字节增长**（两次分别挂起 15 分钟与 20 分钟，
#      缓存字节数完全不增），改为
#      `python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple --only-binary=:all: keybert`
#      后一次装完（现场 1 次成功）。
#   3. `jieba` 在 PyPI 上**只有 sdist**（无 wheel）：`--only-binary=:all:` 会报
#      `ERROR: Could not find a version that satisfies the requirement jieba (from versions: none)`；
#      它是纯 Python 包，直接 `python -m pip install jieba` 会本地构建 wheel 并成功
#      （现场实测 `jieba-0.42.1-py3-none-any.whl`，19.3 MB）。
#
# **后端口径：优先复用仓库自有 `models/bge-m3`，不引 sentence-transformers 后端**
# ---------------------------------------------------------------------------
#   * `text_variants.RepoEncoderEmbedder` 是 `n3d_qa_learn.encoders.HFTextEncoder`
#     的**薄适配**（CLS pooling + L2 归一化），**优先**使用；
#   * 它**必须**继承 `keybert.backend.BaseEmbedder`：现场核实 keybert 0.9.0 的
#     `select_backend()` 对「不是 BaseEmbedder 实例」的对象一律**回落到**
#     `SentenceTransformerBackend("paraphrase-multilingual-MiniLM-L12-v2")`
#     ——即**静默尝试下载一个模型**；继承是「只复用仓库自有 bge-m3、绝不下载」
#     这条契约的唯一实现方式；
#   * keybert 0.9.0 的 `doc_embeddings` 形参是 `np.ndarray`（**不是**老版本的布尔开关）；
#     传 `True` 会在 `doc_embeddings[index].reshape(1, -1)` 处抛
#     `TypeError: 'bool' object is not subscriptable`。本模块固定传 `None`
#     （由 keybert 在本次调用内现算文档嵌入，纯前向、确定性）；
#   * 离线口径：`HF_HUB_OFFLINE=1` + `TRANSFORMERS_OFFLINE=1` + 本地
#     `models/bge-m3`（9 文件 2.29 GB，含 `sentence_bert_config.json` /
#     `modules.json`），现场实测**不需要联网**即可跑通关键词支；
#   * 若仓库自有编码器路径不可用，`build_keyword_backend(...)` 在
#     `allow_sentence_transformers_fallback=True` 时回退到 sentence-transformers
#     后并**在产物 `keyword_backend.note` 中如实登记失败原因**；CLI 提供
#     `--no-st-fallback` 关闭回退（此时直接**可读报错 + 退码 1**）。
#
# 现场实测运行时版本（第 9 轮）
# ---------------------------------------------------------------------------
#   keybert 0.9.0 / jieba 0.42.1 / scikit-learn 1.9.1 / scipy 1.18.1
#   joblib 1.6.0 / threadpoolctl 3.7.0 / narwhals 2.26.0 / cloudpickle 3.1.2
#   sentence-transformers 6.1.0（**未使用其后端**）

# 依赖清单（第 6 轮新增 `transformers` 一族）
# ---------------------------------------------------------------------------
#   transformers          # 通用 HF 编码器适配器（encoders.HFTextEncoder）
#                         #   （**继承下条**：第 9 轮新增 keybert 一族后，它既是可选依赖，
#                         #     也经由 keybert -> sentence-transformers -> transformers 成为
#                         #     传递依赖；本机实际版本仍为 5.18.0，未再升级）
#   tokenizers            # transformers 传递依赖（XLM-R sentencepiece 快分词器）
#   huggingface_hub       # transformers 传递依赖（模型下载 / revision 锁定）
#   safetensors           # transformers 传递依赖（本仓库 bge-m3 无 safetensors 变体，
#                         #   但 transformers 仍要求该包存在）
#   hf-xet                # huggingface_hub 传递依赖（**本环境须禁用**，见下）
#   regex / requests / tqdm / pyyaml / filelock / packaging / typing-extensions 等
#
# **现场实测的下载口径（不得省略）**
# ---------------------------------------------------------------------------
#   1. huggingface.co **直连超时**，必须设置 `HF_ENDPOINT=https://hf-mirror.com`；
#   2. `hf-xet` 的 CAS 服务在镜像下返回 `401 Unauthorized`
#      （`RuntimeError: ... CAS Client Error: HTTP status client error (401 Unauthorized),
#      domain: https://cas-server.xethub.hf.co/v2/reconstructions/...`），
#      必须设置 `HF_HUB_DISABLE_XET=1` 走普通 HTTP 下载；
#   3. 模型 revision 固定为 `5617a9f61b028005a4858fdac845db406aefb181`（**不得浮动 main**）；
#   4. 下载目标 `models/bge-m3/`（仓库根），驱动命令见
#      `python -m n3d_qa_learn.encoders_run fetch`。
#
