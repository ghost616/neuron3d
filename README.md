# N3D：三维神经元空间架构

## 一、工程介绍

N3D 是一个受生物大脑启发的神经网络原型：神经元分布在三维空间中，每个神经元带有若干**输入突触**与**输出突触**，突触自身也有三维坐标；只有当某个输出突触与某个输入突触的空间距离不超过阈值 `D` 时才允许传递数据。换句话说，谁能连到谁，不靠事先画好的结构图，而由几何位置决定。

**核心思想是让连接由几何距离决定**：距离门限天然带来稀疏连接，因此不需要、也禁止把连接权重铺成一张稠密的权重矩阵——连接权重按「边」为单位参数化，每条被几何判定成立的连接各自持有自己的可学习权重。稀疏不是事后剪枝出来的结果，而是空间结构的直接产物。

**研究定位**：本项目探索的是「空间稀疏连接 + 分层有向拓扑」这条路线本身——这种受几何约束的网络能否训练起来、能否随空间规模与形状扩展下去。目标不是刷准确率，而是把这条机制路线做成可运行、可验证、可迁移的工程原型。

**工程现状**：仓库包含一期基础原型（随机三维放置 + 突触级连接）、二期球形有向拓扑（规则堆积 + 分层递推）、三期形状变体（把空间形状泛化为球体 / 立方体 / 圆柱体），以及配套的三维可视化工具；另有 `framework` 模块维护仓库根级共用文件。合计五个模块，各代独立成模块，后一代不修改前一代代码。

## 二、模块功能介绍

| 模块 | 定位 | 关键特性 |
|---|---|---|
| `framework` | 系统框架 | 仓库根级共用文件（README / requirements / .gitignore） |
| `n3d_proto` | 一期原型 | 神经元与突触随机三维放置；输入层接输入突触、输出层接输出突触；四步闭环迭代 T 轮；验证机制可跑通 |
| `n3d_sphere` | 二期：球形有向拓扑 | FCC 规则堆积放置；突触按半球切分；单遍分层 DAG 递推；双副本展开；输入/输出判据由突触孤立性决定 |
| `n3d_shape` | 三期：形状变体 | 把空间形状泛化为球体 / 立方体 / 圆柱体（形状 = 生长度量）；自包含实现，一期二期零改动 |
| `n3d_viz` | 三维可视化工具 | 读取训练产物，导出自包含交互式 HTML + 点云 PLY + 线框 OBJ；GUI 与 CLI 双入口；支持展示输入/输出全连接层 |

**`framework`（系统框架）**：维护整个仓库的根级共用文件——工程入口文档、依赖清单与版本控制忽略规则。它不承载任何网络逻辑，只保证各代原型共享同一份安装方式与同一份仓库约定。

**`n3d_proto`（一期原型）**：最早的空间神经元实现，也常被当作机制基线。神经元与突触的坐标在随机放置后固定，输入层把数据送进全部神经元的输入突触，输出层从全部神经元的输出突触读出，中间由四步闭环迭代若干轮完成信号在空间中的传递。它还配套了一套独立的自检机制，便于在改动或换机后快速确认工程本身处于可用状态。

**`n3d_sphere`（二期：球形有向拓扑）**：把空间从「随机撒点」推进到「规则堆积」——神经元按 FCC（面心立方）规则放置，突触按半球切分以获得明确的方向性，连接按神经元对判定，前向计算改为单遍逐层递推，并以双副本展开的方式在分层有向无环图上推进。输入与输出的选取判据由突触的孤立性决定，而不是靠固定的层编号。

**`n3d_shape`（三期：形状变体）**：一期与二期把「空间」默认为球体，本模块把这一假设泛化为可配置的空间形状——球体、立方体、圆柱体，统一由形状对应的生长度量与尺寸窗口驱动坐标生成。它与上游完全解耦：本模块自包含实现，一期与二期代码零改动。

**`n3d_viz`（三维可视化工具）**：对训练产物做几何与拓扑的直观呈现。读取任意符合 N3D 拓扑约定的产物文件后，一次性导出三件套——自包含的交互式 HTML 视图、点云 PLY、线框 OBJ。既提供图形界面（选择产物、调节显示阈值），也提供命令行入口；对带输入/输出全连接层的产物，还能额外展示两端全连接层的结构与抽样连线。

## 三、快速开始

先安装运行依赖：

```bash
pip install -r requirements.txt
```

依赖清单位于仓库根目录，包含 PyTorch（CPU 即可运行，有 CUDA 时自动选择 GPU）、torchvision 与 numpy。

装好后可以直接运行各模块。下面每一条都是对应模块的最简入口或最简自检命令：

```bash
# 一期原型：最简自检命令
python n3d_proto/train.py --smoke-test

# 二期球形有向拓扑：最简自检命令
python n3d_sphere/train.py --smoke-test

# 三期形状变体：最简自检命令（默认球体，可用 --shape 切换立方体 / 圆柱体）
python n3d_shape/train.py --smoke-test

# 三维可视化：读取一个训练产物，一次性导出 HTML + PLY + OBJ
python -m n3d_viz -c <训练产物>.pt

# 三维可视化：不带参数运行即打开图形界面
python -m n3d_viz
```

关于各模块的正式运行方式、可调参数与验证脚本，请阅读各模块自己的说明文档：`n3d_proto/README.md`、`n3d_sphere/README.md`、`n3d_shape/README.md`、`n3d_viz/README.md`——它们与本工程位于同一仓库，逐代记录了完整的机制细节、参数口径与验证方式。
